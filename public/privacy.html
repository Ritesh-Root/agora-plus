AGORA+

Privacy

This page describes a household server you run yourself. AGORA+ does not operate an account for you, and this is not an Amazon privacy policy.

What is stored

On the server disk, under AGORA_DATA_DIR (the default folder is .agora-data next to the process): facts you asked it to remember, tasks, approvals that are still waiting, and the text of finished plans. The live office room stays in memory and is gone when the process stops.

If you turn on Amazon Bedrock or Amazon Polly, the text of a question or a spoken line is sent to Amazon Web Services in the region you set. If you set a Firecrawl or Exa key, a web question is sent to that service. If those keys are unset, the server does not call them.

Who can see it

Anyone who can read the server's files can read the household. Anyone who has the MCP bearer token can call the household tools. If you set a household passcode, the household pages on this site also ask for that passcode. There is one household on the server, not a separate account per person.

How to delete it

Ask the server to forget a fact and approve that request, or complete a task in the household panel. To remove everything stored on disk, stop the server and delete the data directory. That does not delete anything in an Amazon account, and it does not delete keys you stored in a password manager or in AWS.
